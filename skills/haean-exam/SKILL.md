# 회차 구성

`scripts/haean-tool plan --exam EXAM --subject SUBJECT`로 원자료 기반 정수 배정을 얻는다. 기본값은 최신 자료의 최근 3개년이며 사용자가 다른 기간을 지정하면 따른다. PSAT 7급 추가채용을 제외하려면 `--exclude-extra`를 사용한다.

다음 내용을 `runs/회차명/assembly.json`에 기록한다: 시험·급수·과목, 자료 구간, 번호별 유형·소재·난도·문항 경로·검토 상태, 공유 지문 세트 ID, 부족한 슬롯. 이 파일은 총괄 또는 assembler 한 명만 수정한다. 여러 출제자는 각자 배정받은 run에만 작성한다.

LEET 추리논증은 `src/haean/prompts/leet_editorial.md`의 회차 기준을 읽고 개별 문항 윤문 전에 소재·판단 구조의 중복을 조정한다. `full_exam.build`는 전체 슬롯 개요를 각 묶음의 `context.json`과 `request.md`에 전달한다. 이는 배정표 수준의 대조이므로 완성 문항도 원문 쌍으로 다시 확인한다. 1번의 규범 견해·주장 중심 배치는 선호이며, 특정 표본의 소재 개수나 글자수 통계를 보편적 상한으로 강제하지 않는다.

대량 출제는 독립 문항 묶음을 writer 역할에 나눠 최대 3개씩 병렬로 진행한다. 공유 지문 2문항은 한 출제자가 함께 설계한다. 각 묶음은 독립 검토를 통과한 뒤 회차에 편입한다.

유형 합계 외에도 다음을 검토한다.
- 인접한 고부담 문항, 소재·논리 골격 중복, 누적 독해·계산 부담.
- 5급 과목당 40, 7급 과목당 25문항과 세트 구성. 누락된 실제 문항을 배정표만으로 완성 처리하지 않는다.
- 정답 번호 분포·연속. 번호를 바꾸면 선지·정답·해설의 참조를 함께 수정하고 다시 검토한다.
- 정답을 5문항마다 1~5가 한 번씩 나오는 식으로 맞추지 않는다. `assembled.json`의 `composition_observations`에서 실제 배열과 계획 대비 난도 변경을 확인한다. 관찰값은 자동 합격 점수가 아니며, 난도 변경은 원래 배정과 실제 과제를 대조해 결정한다.
- 회차의 공유 지문 관계, 문제와 해설 번호, 텍스트로 보존되지 않는 도표·수식.

HWP는 `../haean-layout/SKILL.md`에 따라 기존 양식에 내용을 넣는다. LEET·PSAT은 같은 틀에서 시험명·과목 제목을 바꾼다. HTML을 HWP로 가장하거나 페이지 수를 검증 없이 확정하지 않는다. 생산 가능량은 실제 사람 수정 시간과 채택률을 보고 추정한다.
