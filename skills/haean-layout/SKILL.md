# 기존 양식에 내용 넣기

사용자가 제공한 HWP 원본을 복사해 채운다. LEET와 PSAT은 같은 편집 틀을 사용하고 시험명·과목 제목과 문항 내용만 바꾼다. 급수별 문항 수와 회차 구성은 haean-exam의 명세를 따른다. 새 문서로 틀을 다시 그리지 않는다.

저장소 루트는 이 스킬의 실제 경로에서 두 단계 위다. `docs/LAYOUT.md`에서 지원하는 원본과 검증 범위를 확인한다. 원본 문제지·해설지, 확정된 candidate.json과 brief.json을 가진 run 경로를 사용한다. 원문 HWP·폰트는 로컬 자료이며 Git에 올리지 않는다.

## 삽입

`./haean setup-layout`은 고정 버전의 읽기/MCP 엔진과 Java 삽입 도구를 설치한다. JDK 17 이상이 필요하다. 인증/API 키가 필요하지 않다.

```sh
./haean tools layout-fill RUN --template ORIGINAL.hwp --out OUTPUT.hwp --title '해안 LEET 추리논증 검토용'
./haean tools layout-fill RUN --template SOLUTIONS.hwp --out ANSWERS.hwp --title '해안 LEET 추리논증 검토용' --kind solutions
```

PSAT은 제목을 예컨대 `해안 PSAT 7급 자료해석 검토용`으로 지정한다. 과목명은 brief에서 읽는다. 여러 run을 공백으로 나열하면 순서대로 채우며 `--start`로 시작 문항 번호를 지정한다. 다른 시험·과목은 한 파일에 섞지 않는다.

현재 어댑터는 제공된 **40문항 빈 문제지·해설지 마스터**를 인식한다. 최신 CA 완성본을 빈 양식처럼 입력하면 거부한다. 지원하지 않는 원본에 문자열 치환을 억지로 적용하지 말고, 원본 구조를 읽어 새 어댑터를 만든 뒤 시험한다. 25문항·20문항 회차는 내용·페이지·전체 문항 수 안내까지 검증하기 전 확정본으로 표시하지 않는다.

도구는 제목, 지문/보기 박스, 이름 있는 문단 스타일, 어절 줄바꿈, 실제 표 셀을 사용한다. 문제지의 예시 표와 해설지의 예시 정답·회차 총평을 새 결과에 섞지 않는다. 답안은 candidate의 동일한 버전에서 문제지와 함께 만든다. 논리·표의 수치·단위를 양식에 맞추려고 임의로 줄이지 않는다.

LEET 추리논증은 `docs/LAYOUT.md`의 문단 스타일 계약도 확인한다. 표제의 굵기, 사례·발언의 내어쓰기, 발문 줄바꿈과 빈 단을 실제 출력에서 점검한다. Ctrl+7/8이라는 단축키 번호를 문서의 스타일 ID로 사용하지 않는다. 글자수와 실제 줄 수를 구분하고, 특정 마스터에서 측정한 슬롯별 상한을 다른 시험의 고정 제한으로 일반화하지 않는다.

## 확인

1. `.receipt.json`의 원본/문항 해시, 작성·미작성 슬롯과 재읽기 결과를 확인한다. 원본은 덮어쓰지 않는다.
2. **LEET와 PSAT을 각각 한글에서 열어** 제목과 반복 머리말, 본문·보기·선지, 표 셀과 숫자, 문항·정답 번호, 페이지 넘김을 확인한다. 두 종류를 하나의 테스트 결과로 합치지 않는다. 해설지도 별도로 확인한다.
3. 한글에서 PDF로 저장한 뒤 전체 작성 페이지를 렌더해 잘림·겹침·폰트 대체·빈 페이지를 검사한다. 원본의 Q1·Q2·Q40은 안내문 때문에 공간이 다르다. 넘치는 문항은 편집자에게 분량/배치 조정을 넘기고 내용 수정은 출제 검토로 돌린다.
4. 결과와 한계를 별도 검증 기록에 남긴다. 재읽기 성공, Rust PDF 출력, HWP 내부 검사만으로 한글 시각 검증이나 99% 재현을 주장하지 않는다. 미작성 슬롯·미검증 수식/그림이 있으면 검토용이다.

MCP의 hwp_info/read/grep/convert는 원본 조사에 쓸 수 있다. 자동 렌더는 보조 검사다. 현재 시험한 출력 경로는 **hwplib로 원본에 삽입하는 layout-fill**이다. hwp_new로 다시 만든 HWP는 한글 호환성을 확인하지 않았으므로 이 작업의 기본 출력에 사용하지 않는다. `layout_verified`와 `delivery_ready`는 실제 확인 없이 바꾸지 않는다.

PSAT 7급 전체 25문항을 출력할 때에는 `layout-fill ... --exam-size 25`를 명시한다. 26–40번 슬롯과 정답표가 자동 정리되지만, 실제 문항의 전 페이지 렌더·안내 문항 수·전체 쪽수·정답 상자는 다시 확인한다. 이 옵션은 정확히 25문항을 1번부터 채운 PSAT 7급에만 허용된다.
