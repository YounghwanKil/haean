# PSAT 출제

Codex가 직접 초안을 쓴다. 저장소의 `src/haean/prompts/haean.md`, `src/haean/prompts/psat.md`와 배정 run의 `request.md`, `draft.schema.json`을 읽는다. 급수와 과목을 명세에 고정한다. PSAT를 LEET의 난도만 낮춘 형태로 취급하지 않는다.

| 과목 | 우선 설계 | 별도 검증 |
|---|---|---|
| 언어논리 | 일치·추론·논증·논리의 판단 과제 | 미언급/거짓, 전제/결론, 강화/약화 방향 |
| 자료해석 | 표·단위·모집단·시점·분모 | 실제 표 수치와 식의 일치, %/%p, 합계·반올림 |
| 상황판단 | 규정·사례·일정·배치의 닫힌 조건 | 해 존재·유일성, 예외 적용, 동점·기한 경계 |

전문 없는 통계 행은 유형·길이·배치의 참고다. 정답이나 누락 그림을 복원하지 않는다. 자료해석에서 실제 그림이 필요하면 표만 있는 문항을 그래프 문항이라고 내보내지 않는다. 생성한 통계는 가상 자료라고 밝힌다.

5급 40문항과 7급 25문항 구성은 별도로 다룬다. 7급 2019 예시는 통계 집계에서 제외한다. 최근 3개년의 2025 추가채용 포함 여부를 유지한다. 공유 지문은 2문항에 동일한 지문·표를 쓰되 서로의 정답을 누설하지 않아야 한다.

초안 경로에 JSON을 저장하고 사용한 자료 ID, 재검산 결과, 원문 확인이 필요한 부분을 총괄에게 반환한다. 독립 검토는 다른 역할이 수행한다.
