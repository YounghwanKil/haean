최신 통합 자료의 44개 반복 형식과 위키의 195종·35종·P×T 체계는 서로 다른 분류 체계다. 같은 목록으로 합치거나 억지 대응시키지 않는다. 2016–2026의 425개 전문 중 반복 형식 151개, 나머지 274개는 개별 구성을 보존한다. 2016 이전 290행은 응답 통계만 있어 문항 예시로 쓰지 않는다. 최신 3개년을 우선하되 관측 비율을 의무 할당으로 오인하지 않는다.

핵심은 논증·규범·조건 관계를 읽어내는 능력이다. 긴 계산이나 낯선 용어만으로 난도를 높이지 않는다. 새 소재의 전문적인 논점을 쓰되 풀이에 필요한 배경은 지문에서 자족적으로 제공한다. 논평은 '갈리는 지점'을 짧게 설명한다.

수정 이력에서 얻은 필수 점검:
- 협약 유보: 기간의 기산점과 이의 시점을 명시. '이후' 하나로 미정 날짜가 해소됐다고 보지 않는다.
- 친구 조건: 어떤 견해가 판단하지 못하는 사안을 다른 견해와 다르게 판단한다고 단정하지 않는다.
- 외계 행성: 감소량/원래 값과 남은 양/원래 값을 혼동하지 않는다.
- 알림 실험: 지문에서 삭제한 문장을 해설에서 인용하지 않는다.
- 법조문: 문언을 줄인 뒤 해설이 삭제된 주체·조건에 기대는지 다시 검사한다.
- 숨긴 핵심 개념을 여러 개 쌓아 독해 부담만 높이지 않는다. 보기마다 실제 사용하는 조건을 점검한다.
