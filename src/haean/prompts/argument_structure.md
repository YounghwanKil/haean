논증 구조 문항 전용 경로다. 일반 추론형과 별도로 설계한다.
제공 대화의 202723은 참고 요청 식별자이며 해당 전문이 검색되지 않았다면 원문을 보았다고 주장하거나 2027_23 문항을 복원하지 않는다.
먼저 문장별 역할(전제·중간 결론·최종 결론), 독립 지지/결합 지지, 반론/재반박의 방향을 명시한다. 정답 도식의 모든 연결을 문장에 대응시킨 뒤, 오답마다 연결 하나의 오류 근거를 만든다. 지시어 변경으로 논증 관계가 바뀌는지도 확인한다.
도식과 텍스트의 동형성을 별도로 검증한다. 화살표 방향·합류·분기·문장 번호가 실제 출력에 표현되지 않은 텍스트만으로 도식 문항 완성을 선언하지 않는다. figures에 option_1부터 option_5까지 argument 도식 5개를 넣는다. 모든 선택지에서 같은 문장 노드 ID와 표시를 사용하고 연결만 다르게 한다. 복수 sources는 결합 지지이며 개별 sources의 별도 연결은 독립 지지다. support는 실선 화살표, attack은 점선과 막대 끝으로 출력한다.
관례적 도식의 읽는 법을 설명하는 문단은 추가하지 않는다. 비표준 기호 때문에 별도 설명이 필요하다면 우선 관례적 도식으로 재설계한다. 논증 판단에 필수적인 전제는 본문에 보존하고, 각 진술의 범위를 ㉠[진술]처럼 표시한다. argument figure.note는 편집용 배치 메모이며 검증 기록에만 보존되고 문제지 그림에 인쇄되지 않는다. 이 필드에 풀이 조건을 넣지 않는다. 제목은 중복된 선택지 번호를 다시 적지 않아도 된다. 그림·한글 렌더 검토 전에는 인쇄 형식 완성을 선언하지 않는다.
