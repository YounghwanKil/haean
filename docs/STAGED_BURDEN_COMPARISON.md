# 단계형 출제 지침 후보 비교 — 2026-10-19

후보를 기본 하네스에 반영하지 않았다. 동결된 비교기의 결론은 `reject_regression`이며, 두 제품군에서 일관된 개선이 확인되지 않았다. 이 결과는 해당 두 공개 개발 과제의 모델 평가다. 전문가 품질이나 통계적 성능 차이를 입증하지 않는다.

## 조건

- 기존 단계형 경로의 LEET 추리논증·PSAT 5급 자료해석 과제 각각에서 baseline/candidate를 3회씩 실행했다. 예정 12건 모두 완료했으며 실패·부적격 결과를 제외하지 않았다.
- 요청 모델은 `gpt-6-astra`다. 실제 backend model ID는 실행 응답에 노출되지 않아 `null`로 기록했다. Codex 구독 실행이며 API 비용으로 환산하지 않았다.
- 검색 입력, 과제, 수정 예산 1회, 평가기와 프로토콜 v2를 고정했다. 한국어 humanizer는 양쪽 모두 적용하지 않았다. 출제 후 새 세션의 독립 풀이·편집 검토와 별도 고정 평가를 실행했다.
- 양쪽은 같은 출제 과제에서 각각 새 소재와 문항을 생성했다. 같은 문항을 두 지침으로 교정한 비교가 아니므로 개별 성공을 패치의 인과 효과로 단정하지 않는다.
- 후보는 두 과목의 설계 지침 12줄만 바꿨다. 소재 단계의 예정 정답 재검증, 최소 풀이, 조건의 기여, 일관된 오답 경로를 명시한 변경이다. 후보 패치 SHA256은 `f650da70b3fb4cb20b9d31f87324a878e0f775ef217b586fa5492aef007be573`다.
- 실험 명세 SHA256은 `42e5ba62b5da3746a29cdd9faef03e9595c87d403abec8906161b8a511ed3b0f`다. 별도 고정 checkout에서 실행했으므로 진행 중인 main의 코드 변경을 섞지 않았다.

## 결과

|---|---:|---:|---|---|
| LEET 1 | 3.250 | 3.000 | 예 | 예 |
| LEET 2 | 2.875 | 3.000 | 아니요 | 예 |

| PSAT 자료해석 1 | 3.000 | 3.250 | 예 | 아니요 |

점수는 0–4 척도 8차원의 평균이다. 부적격 문항의 점수도 진단용으로 남겼으며 채택 가능한 품질 점수로 해석하지 않는다. 양쪽 적격은 각각 5/6이지만 제품군별 실패가 다르다. 고정 비교기의 제품군 차이는 LEET −0.0833, PSAT 자료해석 +0.0417이고 PSAT의 적격→부적격 퇴행을 다른 반복의 적격성 개선 사례로 상쇄하지 않는다.

PSAT 후보 1은 수정 후 문항의 수학적 계산이 맞더라도 계산 검증용 식이 기존 AST 노드 제한을 넘어 부적격이다. 실행 도중 제한을 바꾸거나 결과에서 제외하지 않았다. LEET baseline 2는 해설이 독립된 다른 가정의 사실을 빌려온 문제가 남았다. 후보에서도 쉬운 보기만으로 핵심 판단을 우회하거나 같은 계산을 반복하는 문제가 관찰되어, 조건 기여 점검을 명시하는 것만으로 선택지 품질이 확보되지는 않았다.

평가기의 설명도 원문 대조가 필요했다. LEET 후보 3의 평가에는 수정 뒤 독립 재풀이가 없다는 서술이 있었지만 실제 기록에는 새로운 세션의 재풀이가 있다. 평가 원문과 점수는 고치지 않고 별도 감사에서 사실 오인을 기록했다. 이 한계까지 고려해 작은 평균 차이를 과해석하지 않는다.

캐시 입력은 입력 토큰의 일부이며 추론 출력은 출력 토큰의 일부다. 중복 합산하지 않았다. job 시간 합은 병렬 실행의 실제 경과시간과 다르다. 토큰·시간 차이 역시 소규모 실행 관찰이며 일반 비용 예측은 아니다.

기본 지침을 유지하고 후보·초안·수정본·검토·점수·실행량을 로컬 `experiments/staged-burden-20261019`에 보존했다. 별도 봉인 평가·전문가 교정·실측 난도·다른 PSAT 과목·7급·언어이해·회차 전체·native 한글 출력은 이 비교의 검증 범위가 아니다. 후속 후보는 이번 실패를 근거로 새 명세와 예산에서 비교한다. 이미 종료한 이 실험의 평가기·과제·결과를 고쳐 재사용하지 않는다.
