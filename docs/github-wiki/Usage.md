# 어디에 입력하나요?

## 일반 터미널에서 시작

macOS의 터미널·iTerm·VS Code 터미널에서 실행합니다. 아직 Codex 대화 화면을 열지 않은 상태입니다.

```bash
haean
haean --madmax
haean --madmax "PSAT 5급 언어논리 40문항을 유형 구성부터 독립 검토까지 진행해줘"
```

`haean`은 설치 시 만든 실행 명령입니다. 어느 폴더에서 실행해도 설치된 해안 저장소를 작업 폴더로 삼고 Astra를 지정해 Codex를 엽니다. 별도 shell alias는 필요하지 않습니다. 현재 작업 폴더의 자료를 자동으로 가져오지는 않으므로 외부 자료는 경로를 알려주세요.

`./haean`은 **현재 폴더의 haean 파일**이라는 뜻입니다. 설치 전이나 저장소 안에서 직접 실행할 때 사용합니다.

```bash
cd /path/to/haean
./haean --madmax
```

`command not found: haean`이면 설치 폴더를 PATH에 넣거나 다음처럼 실행합니다.

```bash
~/.local/bin/haean --madmax
```

`./install.sh`가 안내하는 PATH 설정을 사용하세요. 다른 저장소의 기존 haean 명령은 설치기가 덮어쓰지 않습니다.

## 이미 Codex 안에 있다면

Codex 앱에서 해안 프로젝트를 연 뒤, 또는 터미널의 Codex 대화 입력창에서는 다음처럼 자연어로 요청합니다.

```text
LEET 추리논증 40문항 모의고사 구성부터 잡아줘.
PSAT 7급 자료해석 25문항을 만들고 독립 검토해줘.
새 검토의견을 읽어 문항 수정과 위키에 축적할 지식을 구분해줘.
기존 HWP 양식으로 문제지와 해설지를 출력하고 배치를 검토해줘.
```

`haean` 런처는 시작할 때 총괄 스킬을 자동으로 연결합니다. 이후에는 위 예시처럼 스킬 이름 없이 요청하면 됩니다. 총괄은 회차 구성, 과목별 출제, 독립 검토, 위키 축적, 양식 출력 중 필요한 절차를 선택합니다. `$haean`이나 `$haean-psat`을 붙여 사용할 스킬을 명시할 수도 있습니다.

Codex 앱에서는 해안 프로젝트의 지침과 스킬 설명을 바탕으로 자연어 요청을 연결합니다. 다른 폴더에서 연 일반 Codex에는 해안 스킬이 자동 설치되지 않습니다.

대화창에 `./haean`을 쓰면 시작 명령을 실행하는 대신 모델에게 그 문자열을 요청하게 됩니다. 이미 열린 Codex 안에서 또 Codex를 띄울 필요는 없습니다. 앱의 모델은 앱에서 Astra를 선택합니다.

## 화면과 권한

해안 시작 화면에는 물결 로고·지원 시험·STANDARD/MADMAX 모드를 표시합니다. 이어지는 대화 화면은 Codex TUI이며 하단에 실제 모델·현재 폴더·컨텍스트·사용량 한도를 표시합니다. 창이 좁으면 일부 항목이 줄어듭니다. Codex 데스크톱 앱의 외형을 바꾸는 기능은 아닙니다.

`--madmax`는 이번 Codex 실행에 `--dangerously-bypass-approvals-and-sandbox`를 전달합니다. 명령별 승인과 샌드박스를 생략합니다. 일반 `haean` 실행의 권한은 바꾸지 않습니다. 최초로 연 새 폴더의 신뢰 확인은 Codex가 별도로 표시할 수 있으며, 설치기나 런처가 그 선택을 자동 저장하지 않습니다.

## 자료와 결과

설치한 코드에는 팀 원문이 포함되지 않습니다. 허용된 자료를 가져온 뒤 `haean tools import-team /자료폴더` 등으로 색인합니다. 원본·DB·지식 위키·출제 이력은 로컬에 보관합니다. `haean status`는 기록된 작업 상태를 보여 줍니다.

모의고사 요청 시 시험·급수·과목·문항 수·공유 폴더를 지정하면 편합니다. 생성 → 블라인드 풀이 → 수정 → 회차 검토 → HWP 삽입 → 실제 한글 렌더 검토를 진행합니다. 모델 검토를 통과한 예시는 사람의 전문가 승인 전 검토본입니다.

## 스킬 목록

터미널에서 `haean skills`로 목록을 보고 `haean skills psat`로 자세한 예시를 확인한다. `haean skill psat "작업 요청"`으로 바로 시작할 수 있으며 `haean --madmax skill psat "작업 요청"`은 이번 실행에만 승인·샌드박스 생략을 적용한다. Codex 대화창에서는 자연어로 요청하거나 `$haean-psat`으로 스킬을 명시한다. 언어이해 `$haean-reading`은 파일럿이다.

### 큰 시작 로고

`haean` 또는 `haean --madmax`로 진입하면 청록색 대형 HAEAN 로고와 실행 모드·선택 스킬을 표시한 뒤 Codex로 이어집니다. `haean banner`는 모델 호출 없이 시작 화면만 보여주며, `haean banner --madmax`로 모드 표시도 확인할 수 있습니다. 좁은 창은 작은 로고로 전환하고 `NO_COLOR=1`이면 색을 끕니다. 대화형 터미널에서는 로고를 한 줄씩 표시한 뒤 잠깐 머무릅니다(약 1.5초). `HAEAN_NO_ANIMATION=1 haean`으로 지연을 끌 수 있습니다. Codex를 `--no-alt-screen`으로 실행하여 시작 로고가 대화 위쪽 스크롤 기록에 남습니다. 화면 상단에 고정되는 헤더는 아니므로 대화가 길어지면 위로 스크롤해 볼 수 있습니다.
