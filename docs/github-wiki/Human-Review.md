# 사람 검토와 의견 회수

작성한 LEET 추리논증·PSAT 5·7급 문항과 언어이해 파일럿을 사람이 풀고 의견을 돌려주는 흐름입니다. 개별 묶음, `assembled.json` 회차, 텍스트형 언어이해 `book.json`을 지원합니다.

일반 터미널에서 실행하거나, 열린 해안 대화창에 “이 회차의 사람 검토용 문제·해설·응답 양식을 준비해줘”라고 요청하세요.

```sh
haean tools review-packet runs/회차/assembled.json --out runs/검토패킷
haean tools review-collect runs/검토패킷 /받은경로/검토응답.json
```

언어이해는 입력을 `runs/언어이해회차/book.json`으로 지정합니다. 공통지문을 세 문항 앞에 한 번 표시하고, 실제 번호·지문 ID·문항 위치·book 해시를 연결합니다. 원문에 문항 ID가 없을 때 생성하는 패킷 ID는 해당 book 버전에서만 유효합니다. 공통지문을 수정하면 새 패킷을 만들고 연결된 문항을 함께 재검토합니다.

학생에게는 `student` 폴더만 먼저 보냅니다. 정답·해설은 `review` 폴더에 따로 있습니다. 실제 풀이시간, 사전 정답 열람 여부, 선지 판단, 오류 구절과 수정 제안을 응답 양식에 적습니다. 자연어로 받은 실제 의견은 총괄이 원문을 보존한 채 양식으로 옮길 수 있습니다. 미측정 시간이나 하지 않은 검토를 채워 넣지 않습니다.

수집 명령은 인쇄 번호·문항 ID·부모 문항 묶음·버전 해시를 대조합니다. 과거 버전 의견을 현행 문항에 자동 적용하지 않습니다. 수집만으로 부모 상태·feedback·사람 체크포인트가 바뀌지는 않으므로, 추리논증·PSAT의 총괄은 확인한 A/B 의견을 원 묶음에 `feedback --candidate-sha`로 기록하고 수정·재검토해야 합니다. 사람 체크포인트로 남은 수정 필요 상태를 해제할 수 없습니다.

언어이해는 별도 book 형식을 유지합니다. 수집된 의견을 원 book의 지문·문항 위치와 대조하여 수정·재검토하며, 기존 candidate용 `feedback`·`human-checkpoint`나 추리논증의 고정 평가에 넣지 않습니다.

응답 기록은 전문가 승인·실측 난도 인증·최종 납품 승인과 다릅니다. 모델이 작성한 의견에는 `origin=model`을 유지합니다. HTML은 검토용으로, 실제 한글 인쇄 배치 검증을 대신하지 않습니다.

[전체 사용법과 입력 계약](https://github.com/YounghwanKil/haean/blob/main/docs/HUMAN_REVIEW.md)을 참고하세요. 패킷과 응답 원문은 로컬에서 관리하며 공개 Wiki에 올리지 않습니다.
