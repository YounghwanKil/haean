# PSAT 과목별 검토

공통 역할 `haean_blind_solver`와 `haean_editor`를 사용하며, 제작 검토의 `review_prompt`가 급수·과목별 지침을 자동 연결한다. 별도 이름만 붙인 독립 모델 여섯 개가 아니다. 같은 Astra를 정답 없는 새 컨텍스트와 해설 대조 컨텍스트로 나누어 실행한다.

- 언어논리: 미언급과 거짓, 관점 귀속, 강화·약화 방향, 양화와 조건 추론.
- 자료해석: 분모·단위·모집단·시점, 표와 계산식, 반올림 경계, 그래프 축·범례, 계산 부담.
- 상황판단: 적용 대상·예외·우선순위, 날짜 경계, 해의 존재와 물은 값의 유일성, 동점·최적화.

`check`는 run에 `blind-instructions.md`와 `editorial-instructions.md`를 저장한다. 직접 위임할 때에도 이 파일을 전달한다. `blind`와 자동 제작 파이프라인도 같은 선택 함수를 사용한다. 블라인드 지침에는 시험·과목만 추가하며 topic·item_type·정답·제작 의도는 넣지 않는다.

이 제작 검토 지침은 고정된 `evals/protocol.md` 및 품질 평가기와 구별된다. 새 지침을 적용한 결과를 이전 실행에 소급하지 않는다. 성능 개선 주장은 동일한 고정 평가로 baseline과 candidate를 다시 비교한 후에만 한다. 5급 전체 회차의 검토 결과로 7급 성능을 보증하지 않는다. 사람 검토와 실제 풀이 시간은 모델 검토와 따로 기록한다.
