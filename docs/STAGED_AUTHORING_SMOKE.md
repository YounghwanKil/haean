# 단계형 출제 연결 검증 — 2026-10-19

소재 → 설계 → 기존 Draft 작성 → 독립 풀이 → 편집 검토의 선택 경로를 실제 Codex CLI로 실행했다. 연결 기능은 작동했지만, 두 문항의 별도 모델 평가에서 추론 가치는 모두 2/4였다. 이를 출제 품질 향상이나 전문가 승인으로 해석하지 않는다.

## 실행 조건

- 공개 `evals/pilot.json`의 `leet-norm`, `psat5-data`를 각 1회 실행했다. 기존 과제는 변경하지 않았고, 상세 트랙 명세와 유형 대응을 별도로 보존했다.
- 모델 요청은 `gpt-6-astra`, Codex 구독 로그인 경로였다. 서버의 실제 모델 식별자는 별도로 노출되지 않아 `actual_model=null`로 기록했다.
- 수정 예산은 최대 1회였다. 각 수정마다 독립 풀이와 편집 검토를 새 세션으로 실행했고, 최종본은 동결된 rubric으로 별도 평가했다. Humanizer는 적용하지 않았다.
- 패키지 코드를 별도 사본에 고정하고 단계 입력·지침·스키마·검토·사용량을 보존했다. 두 실행의 초기·검토 스냅샷 검사와 최종 후보 연결 검사가 통과했다. 모델의 도구 사용 이벤트는 0건이었다.
- 평가기·프로토콜·rubric·과제는 변경하지 않았다. 기존 평가 입력 형식을 유지했으므로 별도 평가자에게 참고 전문이나 실행 추적 기록 전부를 전달하지는 않았다.

LEET에서는 독립 풀이가 정답을 맞혀도 편집 검토가 문장의 복수 해석을 발견했다. 수정 후 해당 모호성은 해소됐지만, 반복되는 시점 구별과 직접 적용 보기, 일부 약한 오답이 남았다. PSAT에서는 두 선정 조건의 논리적 중복과 보기 사이의 계산 중복이 목표 난도를 약화시켰다. 별도 평가의 독창성 판단은 참고 전문이 없는 입력의 한계도 포함한다. 낮은 독창성 점수를 복제 확정으로 해석하지 않는다.

정답 타당성과 목표 난도·오답 유인력은 별개다. 이 두 사례는 실측 난도·변별도, 전문가 승인, 7개 제품군 전체 또는 회차 전체의 품질을 증명하지 않는다. baseline과 candidate의 같은 조건 3회 반복 비교도 아니므로 성능 차이를 주장하지 않는다.

## 코드와 문서 검사

전체 `pytest` 364개 통과, 해안 10개와 고정 humanize-korean의 스킬 frontmatter/discovery 11개, 역할 TOML 7개를 확인했다. 별도 합성 점검에서는 LEET 추리논증과 PSAT 5·7급 세 과목의 연결, 마지막 수정본의 명세 이탈, 단계 실패 보존을 확인했다.

독립 코드 검토에서 malformed manifest 처리, 과거 검토 파일 변경 감지, 동시 context 편집 소실을 재현하여 고쳤다. 수동 검토는 요청·문항·지침·스키마에 연결하며, 새 문항의 해시만 전달해 과거 결과를 통과시키는 경로를 차단했다. 같은 요청에서 editor가 대조한 blind 결과의 버전까지 묶는 기능은 아직 없다. 해당 경우 새 풀이와 편집 대조를 함께 갱신하도록 검토 스킬에 명시했다.

## 다음 개선

소재·설계 단계가 있어도 핵심 판단을 실제 선지에서 측정하지 않으면 깊이가 늘지 않는다. 다음 후보는 선지별 최소 풀이, 중복 조건, 오답이 요구하는 일관된 오개념을 실제 작성본과 대조해야 한다. 이 실행의 실패 원문을 근거로 후보를 만들고, 고정 프로토콜에 따른 비교 후 채택 여부를 판단한다. 현재 선택 경로를 기본 하네스의 성능 개선으로 자동 승격하지 않았다.
