2026-10-20(KST)에 7급 언어논리·자료해석·상황판단에서 **공통지문 한 쌍씩, 총 6문항**을 작성하고 새 세션 풀이·편집·수정·평가를 실행했다. 각 25슬롯 계획에서 선택한 묶음의 연결 시험이며, 새 75문항이나 전체 모의고사 완성을 뜻하지 않는다.

## 조건과 입력

코드 `ae108a6b1d6e26742c42a79c48aaa823ec3f64c4`와 입력·배정·지침·스키마·실행기를 고정했다. 실행기 SHA256은 `d64028694ee8771b872fb915986785a7c7d98c46ad551cc7a957463f26754657`이다. 기존 배정의 소재·유형·난도·공통지문 관계를 유지하고 새 문항 ID를 부여했다. 외부 설계와 기존 배정의 충돌은 사전에 명시해 작성·편집 입력에 함께 전달했다. 자동으로 모든 충돌을 해결하는 기능을 검증한 것은 아니다.

요청 모델은 `gpt-6-astra`, 실제 backend 모델 ID는 응답에서 확인되지 않아 `actual_model=null`이다. 묶음별 수정 최대 2회, 자동 재시도 없음, 전체 최대 33호출로 제한했다. 실제 호출은 20회다. 초기·최종에 같은 평가 기준을 사용했고, 수정하지 않은 자료해석은 초기 평가를 최종 평가로 재사용했다. humanizer는 적용하지 않았다.

자동 실행 종료 당시 세 묶음 모두 `awaiting_human_review`였으며 기계 검증·모델 편집 검토에서 A/B 및 조립 연결 오류는 발견되지 않았다. 각 묶음에 편집 C 2건이 남았다. 이후 원문쌍 비교에서 상황판단 한 문항의 구조 재사용을 B로 기록해 **상황판단 묶음은 현재 `needs_revision`**이다. 기존 후보·평가 점수는 보존했다. 사람 검토·실측 난도·독창성·한글 인쇄 승인은 없으며 이 수치를 하네스 A/B 비교나 성능 향상의 근거로 쓰지 않는다.

**평가 입력의 한계가 확인됐다.** 작성·편집에는 슬롯별 배정이 전달되지만 이번 평가에는 묶음 공통 `brief`, 작성본, 검토만 전달됐다. 그 결과 일부 문항의 올바른 개별 유형·난도를 공통 brief와 다르다는 이유로 불일치라고 평가했다. 점수와 원문은 그대로 보존한다. 이 차원을 수정한 비교에는 새 평가 입력 계약과 baseline/candidate 재실행이 필요하며, 현재 점수만으로 과목별 우열을 판단하지 않는다. 평가자가 검토 실행 주체를 확인하지 못했다는 서술도 실제 분리 세션의 실행 증거와 구분한다.

## 발견한 문제

- 언어논리의 초기 공통지문 한쪽에 오탈자가 있어 동일성 검사를 통과하지 못했다. 수정 후 새 풀이·편집을 연결했다. 최종 문장 표현과 두 문항의 지문 결합·오답 경쟁력은 보완 대상이다.
- 상황판단의 초기 해설은 부분 부정과 전면 부정을 혼동해 실제 오답 계산 경로를 정확히 설명하지 못했다. 수정 후 의미 오류는 해소됐지만 직접 계산 중심의 낮은 추론 부담과 내부 표기 문제가 남았다.
- 자료해석의 한 보기는 분모를 잘못 선택해도 같은 참·거짓 판정이 나온다. 의도한 오개념을 적는 것과 실제 오답으로 이어지게 설계하는 것은 다르다. 두 표의 정수 양립, 구간 경계의 가능한 양끝값과 계산식 41개는 별도 사후 모델 검산으로 확인했다.
- 자료해석 독립 풀이의 자연어 이유가 중국어로 반환됐다. 원 요청·raw 응답·저장 결과를 대조했으며 해당 입력에는 한국어 응답을 명시하는 지시가 없었다. 원 응답을 번역해 교체하지 않았고, 한국어 출력 지시는 후속 후보로 남겼다.

## 반복 검사와 기록

작성 전 기존 동일 배정 6문항의 실제 원문·해설과 출처 해시를 확인하고, 작성 후 자동 후보 검색과 원문 구조 대조를 분리했다. 자동 경고는 6문항 모두 0이었지만 상황판단 한 문항은 기존 정답 추론과 네 오답 역할을 높은 수준으로 재사용했다. 명세가 고정한 동일 과제와 명세가 고정하지 않은 오답 구성을 구별해 모델 B 의견을 해당 candidate 해시에 연결했다. 새 문항으로 배포하려면 판단·오답 구조를 재설계하고 재검토해야 한다. 나머지 문항도 부분 추론 재사용과 실제 달라진 보기를 구분했으며 전체 독창성으로 승인하지 않았다. 같은 소재 배정을 사용한 이번 시험으로 장기 연속 생성의 자기 반복이 해결됐다고 주장하지 않는다.

실제 20개 호출은 서로 다른 CLI 대화이며 blind에는 해당 수정 버전의 수험생용 내용만 전달됐다. 실행 중 입력·코드·평가 기준·기존 원고는 보존했고 도구 실행 이벤트는 없었다. 모델 목록 갱신 timeout 경고 1건은 있었지만 해당 풀이 호출은 정상 완료했고 재시도하지 않았다. 사용량은 입력 838,915토큰, 출력 67,775토큰이다. 캐시 입력과 추론 출력은 각각 전체 토큰의 일부이므로 중복 합산하지 않는다. 구독 사용량을 API 과금액으로 환산하지 않았다.

최종 6문항과 수정 계보 10버전을 로컬 생성 이력에 명시 등록했다. 검토용 HTML 문제·해설과 빈 사람 검토 양식을 분리해 만들었다. 브라우저 시각 검토, HWP/HWPX·PDF 및 실제 Hancom 렌더는 이번 범위에 없다. 원문·대화·자료·로컬 위키·실행 trace는 공개 저장소에 포함하지 않는다.

로컬 근거는 `_workspace/psat7-model-bundles-20261020`에 보관한다. 다음 과제는 슬롯별 평가 명세 전달, 잔여 문항 편집, 의미 기반 반복 대조와 사람 검토다. 원 결과를 덮어쓰거나 이번 제한된 연결 확인을 전체 제품군의 전문가 수준 품질로 보고하지 않는다.
