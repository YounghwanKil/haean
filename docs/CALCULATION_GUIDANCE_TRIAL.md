# PSAT 계산식 지침: 팀 시험 적용

상태는 **시험 적용 중**이다. 팀에서 실제 생성·검토하고 유지·수정·롤백한다. 출제 품질이 검증된 최종 지침이라는 뜻은 아니다. 이번 변경은 PSAT 자료해석의 중복 가중합 검증식 하나에서 출발했으며 다른 과목의 지침을 강화하지 않는다.

같은 가중합을 반복 전개해 식이 길어질 때 원자료로부터 유도한 동치 축약을 허용한다. 근거를 evidence에 남기며 기대값을 식에 대입하거나 검증 항목을 빼거나 단위·분모·계산 한도를 바꾸지 않는다. 확인되지 않으면 원식을 유지하고 실패를 보고한다.

## 바로 테스트하는 요청

Codex의 해안 작업창에서 다음처럼 요청한다.

> PSAT 자료해석 계산식 시험 지침을 테스트해줘. 동일한 고정 과제·급수·참고자료·모델·수정 횟수로 기존 지침과 새 지침을 비교하고, 생성 원고·계산식·독립 풀이·편집 의견·실패·사용량을 모두 남겨줘. 과제마다 양쪽 최소 3회로 한 차례만 실행해줘. 원자료와 식이 맞는지, 모든 선지 검산이 유지되는지 먼저 보고, 문제가 생기면 후보를 롤백하고 이유를 기록해줘. 평가 기준이나 기존 결과는 바꾸지 마.

이미 만든 원고와 새로 생성한 원고를 비교군으로 섞지 않는다. 기존 지침은 아래 기준 커밋의 별도 checkout에서 실행한다. 자료는 동일한 읽기 전용 스냅샷을 사용하고 baseline/candidate 출력 폴더를 분리한다. 실제 사용한 파일 해시와 모델 요청, 실제 backend ID 확인 여부를 남긴다. 기존 준비 패킷을 재사용하면 옛 지침이 포함돼 있을 수 있으므로 새 지침으로 패킷을 다시 만들고 실제 전달 내용을 확인한다.

## 유지·수정·롤백 판단

- 정답 불일치·조건 누락·단위/모집단/분모 변경·검산 항목 삭제·expected 하드코딩이 새로 생기면 해당 후보 사용을 중단하고 롤백한다. 실패 원고와 의견은 보존한다.
- 기계 검산 통과뿐 아니라 독립 풀이·편집 검토, 추론 가치·오답 기능·풀이 부담과 실행 비용을 비교한다. 한 과목이나 차원의 퇴행을 다른 점수로 덮지 않는다.
- 도움이 되는 부분과 나빠진 부분이 섞이면 한 가지 수정 가설만 다음 후보로 만든다. 차이가 불분명하거나 예산에 도달하면 반복을 멈추고 기준 지침으로 돌아간다.
- 사람이 유지하기로 하면 검토자·문항 해시·판단 근거를 남긴다. 다른 급수·과목이나 회차 전체에 대한 전문가 품질 검증으로 일반화하지 않는다.

`evolve-reflect`가 설치된 브랜치에서는 저장 결과를 원문·품질·비용과 연결해 볼 수 있다. 이 진단 도구가 없더라도 위 생성·독립 검토 절차는 수행할 수 있다.

## 적용 범위와 롤백

우리 해안 기준 커밋은 `f71738c`, 지침만 추가한 커밋은 `04cf626`이다. `prompts/psat.md`는 자료해석 작성·수정에, `psat_data/rules/design.md`는 단계형 설계에 연결된다.

```sh
# 커밋되지 않은 팀 작업이 없는지 확인한 뒤 지침 커밋만 되돌린다.
git status --short
git revert 04cf626
```

기존 작업이 있으면 먼저 보존한다. reset --hard 또는 다른 변경 전체 되돌리기는 사용하지 않는다. 충돌이 생기면 해당 지침 추가 부분만 해소한다. 롤백 후 새 패킷을 생성해 지침이 빠졌는지 확인한다.

## 이번에 실제 확인한 범위

과거 실패 문항의 검증식 하나를 같은 입력으로 Astra에 두 번 작성시켰다(기준 1회·후보 1회). 기준 응답은 AST 노드 107개로 기존 한도를 넘었고 후보 응답은 44개로 통과했다. 후보 계산값은 표에서 독립 재계산한 정확값과 일치했으며 label·expected·unit은 유지됐다. 원고 사본의 해당 expression·evidence만 바꿨을 때 기존 기계 검증 오류가 1개에서 0개로 줄었다. 원본·이전 검토·평가 기록은 변경하지 않았다.

이는 **한 식의 재작성 기능 확인**이다. 신규 문항 생성·전체 문항 품질 비교·최소 3회 반복 평가·새 독립 풀이·전문가 검토는 아니다. 이번 결과만으로 지침의 일반적인 개선 효과를 확정하지 않는다. 전체 자동 테스트 1,932개가 통과했고, 실제 지침 로딩 경로를 확인했다.
