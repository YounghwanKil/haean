# 문항별 평가 입력 v3 실행 확인

2026-10-20. PSAT 7급 언어논리·자료해석·상황판단의 보존된 공통지문 쌍을 초기·최종 원고별로 **6회 재평가**했다. 새로운 문항 생성·독립 풀이·수정은 하지 않았다. [이전 실행](PSAT7_SHARED_MODEL_SMOKE.md)의 점수와 원문은 유지했다.

## 수리한 문제

공통 brief의 유형·난도를 묶음 전체 목표로 사용하는 대신, 원래 배정을 문항 ID별로 전달했다. 언어논리의 상 난도 문항과 대화 분석 문항, 자료해석의 하 난도 단답 문항을 해당 목표로 평가하는 것을 응답 원문에서 확인했다. 목표를 준수했는지와 실제 문면이 그 난도를 구현하는지는 별개로 판단했다.

평가 입력과 과거 초안·검토 연결을 확인하는 기능 변경이다. 기존 rubric·8차원·0–4 척도·pilot 과제는 그대로이며, 프로토콜은 v3로 분리했다. v2 점수와 직접 비교하지 않는다. [사용법](EVALUATION_INPUT.md)을 참고한다.

## 실제 결과

| 과목 | 초기 원고 / 4 | 최종 원고 / 4 | 해석 |
|---|---:|---:|---|
| 언어논리 | 3.0625 | 3.0000 | 초기 공통지문 불일치 기록 유지. 최종의 문장·해설 표현과 선지 판단 부담이 보완 대상 |
| 자료해석 | 3.0000 | 3.0625 | **동일 원고의 반복 평가**. 오답 기능 점수 차이는 개선 효과가 아님 |
| 상황판단 | 2.9375 | 3.0000 | 초기 해설의 부정 범위 문제와 수정본을 구분. 낮은 판단 부담과 후속 구조 반복 지적은 남음 |

이는 생성 하네스 A/B 시험이 아니며, 작은 점수 차이를 성능 향상으로 해석하지 않는다. 언어논리·자료해석은 사람 검토 대기, 상황판단은 후속 구조 반복 의견에 따른 `needs_revision` 상태를 유지한다. 재평가의 `eligible`은 해당 revision의 저장 검토·모델 점수·연결 조건이며, 현재 피드백 해소나 납품 승인을 의미하지 않는다.

요청 모델은 `gpt-6-astra`, 실제 backend ID는 미확인으로 `actual_model=null`이다. 최대 6호출·자동 재시도0으로 실행했고 6개 별도 CLI 대화에서 모두 완료했다. 입력 184,595토큰·출력 17,037토큰을 기록했다. 캐시 입력·추론 출력은 각각의 부분량이며 합산하지 않는다. API 과금액으로 환산하지 않았다.

## 검증과 한계

전체 코드 테스트 **1,222개**, 스킬 frontmatter·discovery 경로 11개, 역할 TOML 7개를 확인했다. 실제 실행·원문 연결 대조 218항목에서 불일치0, 모델 도구 실행0이었다. 기존 실행의 632개 파일, 원문·누적 생성물 DB, rubric·pilot은 보존했다.

최초 사전 점검에서는 과거 의견의 복수 ID 표기와 당시 코드/현재 코드 차이 때문에 모델 호출 전에 중단됐다. 실패 기록을 남기고 코드를 보완했다. 아카이브 검증은 저장된 composition 설계 스냅샷·원입력·배정·초안·검토 연결을 유지하면서 현재 코드와의 일치 요구만 분리한다. 일반 생성·조립의 엄격 검증은 그대로다.

응답에 남은 ‘검토 주체·독립성 확인 자료 부족’은 평가 모델에게 전달된 자료 범위에 관한 판단이다. 별도 CLI 실행·receipt 대조와 구분하며 사람 전문가 승인으로 바꾸지 않는다. 기존 자료해석의 잘못된 분모로도 정답을 얻는 문제, 상황판단의 정답·오답 구조 반복, 실측 난도·전체 회차·실제 한글 렌더는 이번 평가 입력 수리로 해결되지 않았다.

원고·대화·평가 trace는 로컬에 보관한다. 공개 저장소와 GitHub Wiki에는 코드·일반 사용법·합성 테스트·범위를 명시한 결과만 반영한다.
