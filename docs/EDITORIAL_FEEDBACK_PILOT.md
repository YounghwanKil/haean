# 검토의견 반영 후 Astra 비교 — 2026-10-09

팀의 LEET 검토의견을 반영한 편집 지침을 공개 pilot `leet-norm`에서 비교했다. **모델 평가상 개선 신호가 있었지만, 전문가 수준이나 일반적인 출제 성능 향상을 입증한 결과는 아니다.** 원문 문항·팀 의견·실행 로그는 로컬에 보관하고 이 문서에는 집계만 공개한다.

## 실행 조건과 범위

- Baseline: `a79f5e30b3e4a4d3cba82caf1ff1ed2cf1f4bfaa`
- Candidate: `f7d25ed03f2d66c9c8c0f56cce967a4b684a3094`
- Codex CLI `0.160.1`, 구독 로그인, 요청 모델 `gpt-6-astra`
- 같은 공개 LEET 과제에서 각 3회 생성, 실행당 수정 최대 1회, humanizer 미적용
- `codex-prompt-pipeline`: 생성 → 새 컨텍스트 풀이 → 편집 검토 → 필요시 수정·재검토 → 별도 품질 평가
- 평가 프로토콜 v2·rubric·과제·평가기 해시 동일. 원본 DB의 실행 전후 해시 동일
- 실제 생성 입력의 brief·references·retrieval·feedback·note는 각 비교 쌍에서 동일. 후보에 추가한 편집 지침과 `editorial_plan`은 의도한 차이이며, 실제 생성 프롬프트에 포함됐음을 확인

순서는 baseline 3회 다음 candidate 3회로, 무작위 교대가 아니다. 시간·순서 효과와 모델 변동이 섞일 수 있다. 같은 반복 번호를 비교한 것은 같은 문항이나 난수 seed를 고정한 실험이라는 뜻이 아니다. 전체 회차 구성, 자연어 스킬 라우팅, PSAT, HWP 배치를 평가한 실행도 아니다.

## 결과

| 관찰 | Baseline | Candidate |
|---|---:|---:|
| 최종 모델 점수 / 4 | 2.750 / 2.875 / 2.750 | 3.125 / 3.125 / 2.875 |
| 최종 eligible | 2/3 | 3/3 |
| 초안 편집 A 지적이 있던 실행 | 1/3 | 0/3 |
| 초안 편집 A 또는 B 지적이 있던 실행 | 2/3 | 0/3 |
| 수정을 실행한 횟수 | 2 | 0 |
| 모델 호출 | 18 | 12 |

8개 서열 척도의 단순 평균은 2.792 → 3.042, 차이는 +0.250이다. 고정 비교기의 판정은 `candidate_signal`, `auto_promoted=false`, `expert_verified=false`다. 실행 실패를 제외한 집계가 아니며, 6회 모두 실행을 마쳤다. 30회 호출에서 입력 격리를 위반하는 도구 이벤트는 없었다. 호출 시간과 토큰 차이는 이번 실행의 관측값이며 생산 속도나 비용 절감 보장이 아니다.

Baseline 초안 한 건에서는 풀이 정답이 출제 정답과 일치했는데도 편집자가 사례의 적용 시점 조건 누락을 발견했다. 원문과 수정본을 직접 대조해 확인했으며, 수정 후 검토를 통과했다. 다른 한 건은 해설 범위와 과목 표기를 고쳤지만 목표 난도에 관한 B 의견이 남아 최종 부적격이었다. **정답 일치와 validity 점수만으로 채택하지 않는 절차가 필요하다.**

후보 두 번째 문항은 핵심 보기의 추론을 생략하기 어려운 선택지 구성을 보였다. 그러나 후보 첫 번째·세 번째 문항에서는 쉬운 두 보기만으로 정답이 확정되어 다른 핵심 판단을 건너뛸 수 있었다. 오답 품질은 후보에서 2/3/2점으로, 이 문제가 해결됐다고 볼 수 없다. 용어와 해설을 다듬으라는 C 의견도 남았다.

## 판단과 남은 검증

이번 결과는 이미 반영한 팀 편집 지침에 대한 사후 진단이다. 점수를 근거로 추가 후보를 자동 채택하거나 기존 문항을 납품 승인하지 않았다. 최종 공개 문면·해설, 각 단계의 풀이·편집 기록과 점수 근거를 읽고, 원본 입력과 실행 기록을 별도로 감사했다.

- 한 공개 과제의 3회 반복이므로 다른 LEET 유형이나 PSAT 성능으로 일반화하지 않는다.
- 비슷한 난도 우려를 편집자가 C 또는 B로 분류하는 변동이 관찰됐다. 원래 판정을 보존하며 전문가 교정이 필요하다.
- 최종 품질 평가자에게 참고 문항 전문은 제공되지 않았다. 독창성 2점은 근거 부족을 반영한 잠정 점수이며 표절 검출 결과가 아니다. 원문 구조 대조는 별도 절차다.
- 수험생 풀이 시간·선지 선택률·변별도·두 전문가의 봉인 검토는 없다.
- 최신 지침의 회차 전체 소재 배분, 양식 및 HWP 렌더 효과는 별도로 확인해야 한다.

후속 개선은 핵심 추론 우회와 약한 오답의 실제 원문을 근거로 설계한다. 평가기를 바꾸거나 작은 점수 차이에 맞춰 같은 공개 과제를 반복 최적화하지 않는다. 로컬 재현 자료는 `experiments/editorial-feedback-20261009/`의 양쪽 결과·trace, `comparison-manifest.json`, `comparison.json`, `execution-integrity.json`, 총괄 독해 기록에 있다.
