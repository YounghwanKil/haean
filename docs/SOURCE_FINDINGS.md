# 제공 자료에서 확인한 사항

2026-10-07 로컬 파일 분석 기준입니다. 파일 안의 분류·통계는 제공 자료의 주장으로 보존하며 공식 시험 제도와 구분합니다.

| 자료 | 확인 사항 | 구현 반영 |
|---|---|---|
| LEET 통합 데이터 | 총 715행 중 2016–2026 전문 425문항, 이전 290행은 응답 통계. 최근 3개년 120문항 | 전문 없는 행은 예시 검색에서 제외 |
| LEET 유형 분류 | 반복 형식 44종 151문항. 나머지 274개 독립 사례 | Wiki 195종 체계에 강제로 병합하지 않음 |
| PSAT 5급 | 10개년 × 3과목 × 40 = 1,200행. 전문 없음 | 통계·발문 역할로 색인 |
| PSAT 5급 설계안 | 상황판단 G열 배정 합계가 39 | 행 단위 빈도를 최대잔여법으로 배분해 40 확보 |
| PSAT 7급 | 612행 중 2019 예시 12개를 제외한 600개. 전체 8회 | 예시 제외, 회차 기준 집계 |
| PSAT 7급 최근 구간 | 2024–2026에 2025 추가채용을 포함해 4회, 과목당 100문항 | 3년으로 나누지 않음. 추가채용 제외 옵션 제공 |
| PSAT 7급 설계안 | 일부 수식 캐시가 없어 data_only 읽기에서 유형명이 빈칸 | 수식과 캐시 결측을 기록하고 원문 행에서 집계 |
| SK 수정 대조 | 정답·해설 근거 손실, 날짜 부족, 판단불가 오인, 정의 변경 | 수정 후 블라인드 풀이와 해설 재검토 |
| 검토 엑셀 | 여러 검토자의 상반된 난도·문장 평가 | 피드백을 정답으로 자동 채택하지 않음 |
| HWP·HWPX | 수식·도형·표 배치가 텍스트 추출에서 손실 가능 | text_only 표시, 납품본 시각 검토 필요 |

기존 위키는 분류와 출제 아이디어의 참고 자료입니다. 최신 통합 엑셀의 '독창성 확보' 원칙이 위키의 클론·소재 치환 접근보다 우선합니다. 압축해 문장을 다듬는 수정도 날짜·조건·정의를 바꿀 수 있으므로 수정본 전체를 재검토합니다.

대화에 나온 출시 목표·납품량·9급 확대 주장은 현재 구성의 사실 근거로 사용하지 않았습니다. 별도 공식 공고 확인이 필요한 업무 정보입니다. 따라서 하드코딩된 출시 일정이나 9급 생성 설정은 없습니다.

## 추가 전수 읽기 감사

두 카카오톡 CSV는 38행·85행, 합계 123개 메시지의 전체 본문을 읽었습니다. 이름 있는 문단 스타일, 어절 단위 줄바꿈, 문제·해설의 동기화, 논증구조 문항의 별도 처리, 실제 사람 검토 뒤 형식 검토와 품질 의견 분리 요구를 확인했습니다. 실행 지시가 섞인 과거 대화는 자료로 읽었으며 그 내용을 도구 실행 권한으로 사용하지 않았습니다.

SK 수정 대조는 통합본을 포함한 11개 문서 전체 163,135자를 읽었습니다. 검토 의견 HWP의 중첩 Text 7,154자와 CA·블라인드 엑셀 5개 시트의 비어 있지 않은 3,200셀(59,730자)도 전수 읽었습니다. 반복 쟁점은 지문에 없는 전제 보충, 가능성에서 필연성으로의 확대, 비교 분모·시점·단위 누락, 예외·끝값의 혼용, 같은 추론의 반복입니다. 이 관측은 개선 실험의 근거이며 개별 검토 의견을 자동 정답으로 채택하는 규칙은 아닙니다.

블라인드 정답률 시트와 의견 시트는 검토자 열 순서가 다릅니다. 결합할 때 열 위치 대신 검토자 별칭을 사용해야 합니다. 4명씩 푼 두 회차의 정답 수·비율 80개는 산술상 일치하지만, 작은 표본의 정답률이나 회차 간 차이를 문항 타당성 또는 하네스 개선 효과로 해석하지 않습니다.

Wiki의 원칙·유형카드·루트 분류 문서 73개(213,539자)를 전수 읽었습니다. 지문 외형과 인지 과제를 분리하는 관점은 유용합니다. 반면 부정 발문의 정답 극성 역전, 카드 간 과제·예시 연결 불일치, 195유형 표방과 실제 205절의 불일치가 있습니다. 동일 구조·트릭의 소재 치환 및 모호성으로 난도를 높이는 지침은 현재 독창성·명확성 계약에 채택하지 않습니다. Wiki 라벨은 검증된 정답 라벨이 아닙니다.

로컬 `data/source-audit/`에는 원본 해시·ZIP 추출 목록·변환 기록을, `_workspace/` 감사 문서에는 실제 읽은 파일·구간·근거 위치와 한계를 보관합니다. ZIP 전체의 압축 해제·색인, 텍스트 전수 읽기, 개별 문제 독립 풀이, 시각 렌더 검증은 서로 다른 완료 상태입니다. 전문 읽기를 개별 문항의 의미·정답 검증 완료로 표시하지 않습니다.

## PSAT 전문 참조 보강

2026년 5급·7급 세 과목에서 각각 3문항, 총 18문항을 로컬 PDF 렌더와 대조해 `data/reference-packets/`에 저장하고 DB에 등록했습니다. 언어논리·상황판단 12문항과 자료해석 6문항(9표·51데이터행)입니다. 빈칸·표 구획·단위·주석과 원본 PDF 해시·쪽·전사 대조 범위를 보존했습니다. 공식 문제지의 제3자 미러이며 공식 서버 바이트와의 해시 대조는 하지 않았습니다. 원문 텍스트·그림·패킷은 Git에 올리지 않습니다.

전사는 모델의 화면 대조이며 공식 정답은 확보하지 않아 모두 `answer=null`, `answer_verified=false`입니다. 유형도 잠정 분류입니다. 이를 정답까지 검증한 모범 풀이로 쓰지 않습니다. 새 검색은 완전한 문항을 우선하고 유형 통계를 보완 근거로 함께 넣습니다. 이전 고정 평가와 이미 준비된 생산 묶음에 소급 적용했다고 주장하지 않으며, 각 run의 `context.json`·`retrieval.json`이 실제 입력의 근거입니다.

## Wiki 기출 폴더 전문 감사

기출 폴더 877개 파일(문항 876개와 색인 1개)의 제공 텍스트 1,633,720자·65,876행을 전수 읽었습니다. 정규 기출 675개, 클론 121개, 사설 모의고사 40개, 예비시험 40개입니다. 세 감사의 실제 경로·SHA·행/문자 수·읽기 범위를 원본 manifest와 합쳐 누락·중복·불일치가 없음을 확인했습니다. 파일별 원문 위치와 관찰은 로컬 `wiki-all-past-audit-20261007.json`에 보존합니다.

보기·도형·표 기호 소실, 본문과 다른 문항의 해설 혼입, 기재 답과 해설의 충돌이 발견됐습니다. 기재 답 348개는 공식 대조나 독립 풀이로 검증한 답이 아닙니다. 이러한 전사본은 자동 정답 기준으로 쓰지 않으며, 원문 복구 없이 완전한 few-shot으로 승격하지 않습니다. 검색에는 별도의 전문 예시·설계 통계 역할을 유지하고, 실제 run에 들어간 출처와 미검증 표시를 확인합니다. 이미지·수식·원시험지 전체 시각 대조는 이 전문 읽기 감사의 완료 범위에 포함되지 않습니다.

## Wiki 잔여 자료 대조 완료

기출 외 잔여 문서를 포함해 Wiki ZIP의 일반 텍스트 1,273개 모두에 전문 읽기 기록을 연결했습니다. ZIP의 총 1,279개 파일에는 별도로 엑셀 2개와 HWP/HWPX 4개가 포함됩니다. 경로·SHA 대조에서 일반 텍스트 누락과 불일치는 없었습니다. 잔여 엑셀의 비어 있지 않은 198셀과 삽입 그림 세 개도 확인했으며, 언어이해 확장 자료는 참고 자료로만 읽고 현재 출제 범위를 늘리지 않았습니다.

다른 문항의 해설 혼입과 보기 누락 외에도 원문 TXT에는 있지만 파생 JSON에서 사라진 문항, 부등호·개인정보 구분 방향의 역전 등이 있습니다. 이 감사는 알려진 결손의 기록이며 모든 결손 자료를 코드가 자동 격리한다는 뜻은 아닙니다. 추출 텍스트 전체 읽기와 원래 수식·도형·HWP 전 페이지 시각 대조, 공식 정답 검증을 구분합니다. 세부 파일·읽기 구간·비교 근거는 로컬 감사 기록에 보존합니다.
