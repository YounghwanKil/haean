## 실행 조건

- 코드 `37cd05f252bb52354d2492dc30b631d889c77715`를 별도 checkout에 고정했다. 실행기 SHA256은 `36e6d23a0813b26ffc92c8e4c39b9281f7579e7d8b9c3a77470c92f669ee3f65`이며 입력·계획·배정·코드·지침·스키마 해시를 보존했다.
- 네 과목의 명시 ID와 유형·소재·난도 배정을 유지했다. 외부 설계와 계획의 충돌은 기록에 드러내고 선택 문항의 처리 근거를 남겼다. 다른 슬롯의 미해결 정책까지 해소했다는 뜻은 아니다.

## 실제 수정과 남은 문제

- **언어논리:** 정답은 일치하지만 한 보기를 배제하면서 여러 선택지가 함께 사라져, 의도한 일반화 판단 일부를 생략할 수 있다. 편집 C와 오답 기능 2점이 남았으며 수정 없이 종료했다.
- **상황판단:** 정수 최적화의 최대값·달성 구성과 계산이 일치했다. 반복 안내와 일부 오답의 유인력은 후속 편집 과제다. 수정 0회이므로 개선 루프의 효과로 세지 않는다.
- **추리논증:** 짧은 순방향 반례만으로 답을 고르는 초안에 B가 나와 역산을 요구하도록 수정하고 재풀이했다. 그러나 전체 상태 복원이 필수라는 난도 설명은 과장되어 있고, 사후 감사에서 한 오답 설명이 동일한 오독을 모든 보기에 적용하면 성립하지 않는 문제도 확인했다. 기존 최종 평가의 오답 점수는 2점이다. 원래 결과를 바꾸지 않고 추가 검토 항목으로 남겼다.
- **자료해석:** 틀린 계산을 해도 정오가 바뀌지 않는 오답 설명을 B로 잡아 수정했다. 공개 지문·보기·정답은 그대로이며 실제로 정오가 바뀌는 오류 계산으로 내부 설명을 고쳤다. 다만 다른 평균 혼동도 현행 수치에서는 결론이 같고, 일부 판단은 선택지 배열 때문에 생략할 수 있다. 오답 기능 2점과 표기·풀이 효율 보완이 남았다.

평가 입력에 실행 trace 전체가 없으므로 모델의 ‘독립 절차·버전 대응 미확인’ 서술과 실제 실행 증거를 구분했다. 작성 시점의 ‘독립 검토 미수행’ 제작 코멘트도 뒤에 진행된 검토 상태를 덮어쓰지 않는다. 현행 상태는 연결된 trace·후속 검토·receipt로 확인한다.
