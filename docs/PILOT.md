# Astra 파일럿과 첫 개선 실험

2026-10-07, Codex CLI 0.160.1의 ChatGPT 로그인으로 `gpt-6-astra`를 실제 실행했다. API 키·OpenAI SDK를 사용하지 않았다. 7개 제품군에서 후보 문항 1개씩, 비교용 baseline 2개를 생성했다. 생성·독립 풀이·편집·수정·평가를 합쳐 45회 호출했으며, 별도의 런타임·대화형 검토·윤문 테스트는 이 수치에 포함하지 않았다.

이 결과는 전문가 교정 전 **모델 평가**다. 각 과제 1회, 최대 수정 1회이며 합산 점수는 8개 서열 척도(0–4)의 단순 평균이다. 실제 정답률·변별도·전문가 수준을 입증하지 않는다. 실행 원문은 로컬 `experiments/`에, 원문 없는 집계는 [pilot-results.json](pilot-results.json)에 보관한다.

## 텍스트 검토에서 출발한 개선

Astra 개선 담당이 두 baseline의 문항·검토·평가·자료 원문을 읽고 후보를 작성했다. 공통 문제는 쉬운 보기만으로 핵심 추론을 건너뛰거나, 오답의 설명에 적은 실수를 실제로 적용해도 정오가 바뀌지 않는 것이었다.

후보는 최단 풀이 경로, 핵심 판단의 필요성, 오개념을 실제 적용한 결과를 출제 단계에서 확인하도록 했다. 소재·정답을 외우는 규칙은 넣지 않았다. 평가기·과제·rubric·모델·수정 예산은 바꾸지 않았고 비교 두 과제의 검색 입력도 동일함을 확인했다. [후보 패치](pilot-patches/reasoning-001.patch)를 보존했다.

| 같은 과제 | baseline | 후보 | 해석 |
|---|---:|---:|---|
| LEET 추리논증 | 2.75 | 3.00 | 추론 가치 2→3, 오답 품질은 2 유지 |
| PSAT 7급 자료해석 | 2.75 | 3.25 | 개선 신호, 1회 표본으로 일반화 불가 |

비교기의 판정은 `candidate_signal`, `auto_promoted=false`다. LEET 후보 초안에서는 필요조건을 충분조건으로 쓰는 문제를 편집자가 A로 지적했고, 수정 후 재검토를 통과했다. 호출 수가 4→7, 관측 실행 시간이 약 291→515초로 늘었다. 시간은 서버 부하·병렬 실행의 영향도 받으며 생산 속도 보장이 아니다. 최종 점수만으로 초안의 약점과 수정 비용을 가리지 않는다.

후보는 기본 프롬프트에 자동 승격하지 않고 baseline을 복원했다. 후속 실험에서 반복·봉인 평가·팀 검토를 거쳐 판단한다. 출시 코드에는 그 뒤 텍스트 피드백함과 `.txt` 입력 연결을 추가했으며 이 연결 자체의 효과를 위 점수 상승으로 주장하지 않는다.

## 후보의 제품군별 실행 점검

| 제품군 | 최종 모델 점수 | 수정 횟수 |
|---|---:|---:|
| LEET 추리논증 | 3.000 | 1 |
| PSAT 5급 언어논리 | 3.375 | 0 |
| PSAT 5급 자료해석 | 3.250 | 1 |
| PSAT 5급 상황판단 | 3.375 | 0 |
| PSAT 7급 언어논리 | 3.000 | 0 |
| PSAT 7급 자료해석 | 3.250 | 0 |
| PSAT 7급 상황판단 | 3.250 | 1 |

모든 실행이 최종 `awaiting_human_review` 상태로 끝났다. 후보 7개 중 초안 3개에서 A/B 지적이 있었고 한 차례 수정 후 재검토를 통과했다. 위 LEET 조건 문제 외에 전체 통행량과 특정 수단 통행량의 해설 혼동, 배정 상한을 반드시 채워야 하는 정원으로 해석한 문제가 있었다. 나머지 5개 제품군에는 별도 baseline 비교가 없으므로 향상을 주장하지 않는다. 독창성·실제 난도는 추가 원문 대조와 응시 자료가 필요하다.

## 대화형 스킬·윤문·양식

- 7개 해안 스킬과 humanize-korean의 Codex discovery를 확인했다. 현재 런타임에는 custom-role 선택 인자가 없어 역할 지침을 일반 서브에이전트에 전달하는 호환 경로를 사용했다.
- `$haean-review`로 실제 문항을 다시 검토했다. 공개 입력만 받는 별도 Astra CLI 풀이의 도구 이벤트는 0이었다. 편집은 부모 대화를 상속하지 않는 Astra 서브에이전트가 맡았다. 정답이 일치하고 A/B 없이 사람 검토 대기로 끝났으며 문항 해시도 유지됐다. 같은 모델의 컨텍스트 분리이지 모델 간 독립성은 아니다.
- im-not-ai는 고정 submodule의 실제 monolith 역할과 게이트를 실행했다. LEET 지문은 light 경로로 쉼표 2개만 삭제됐다. upstream 변경률 0.16%(표시 0.2%), gate exit 0, 해안 보호 토큰 변경 없음. 이미 양호한 문장에 가까웠고 대폭적인 문체 향상의 근거는 아니다. 윤문본은 별도 보존했으며 생성 평가에는 적용하지 않았다.
- 실제 제공 HWP 문제지·해설지 템플릿으로 layout manifest를 만들었다. Java 인터페이스 미제공으로 `layout_verified=false`이며 양식 출력·렌더 검증은 아직 없다.

다음 실험은 팀의 원문 텍스트 피드백을 근거 문항에 연결해 시작한다. 현재 소수 표본에 맞춘 규칙을 늘리기보다 제품군별 개발 과제 10–20개와 전문가 판단을 확보하고 반복 평가한다. [평가 프로토콜](../evals/protocol.md)을 따른다.

## 자료 감사 후 고정 스냅샷 실행

위 파일럿 이후 검색·자료 처리 변경을 분리된 스냅샷으로 고정하고 `experiments/source-audit-v03-frozen`에서 동일한 7개 제품군 과제를 실제 Astra로 다시 실행했다. 과제당 1회·최대 수정 1회이며 humanizer는 적용하지 않았다. 코드·스킬·평가 파일과 검색 DB를 스냅샷에 복사하여 실행 중 개발 변경과 분리했다. 이전에 개발 중인 디렉터리에서 시작했다가 중단한 실행은 별도 경로에 보존했다.

| 과제 | 모델 점수 / 4 |
|---|---:|
| LEET 추리논증 | 3.000 |
| PSAT 5급 언어논리 | 3.000 |
| PSAT 5급 자료해석 | 3.000 |
| PSAT 5급 상황판단 | 2.875 |
| PSAT 7급 언어논리 | 3.250 |
| PSAT 7급 자료해석 | 3.000 |
| PSAT 7급 상황판단 | 2.875 |

7개 모두 사람 검토 대기로 끝났고 평가상 fatal은 0개였다. 평균은 3.000이다. 오답 품질·독창성·추론 가치의 점수는 여전히 낮은 항목이 있어 전문가 수준이나 실전 변별력을 입증하지 않는다. 앞선 후보 실험과 검색 입력·하네스가 달라 직접적인 성능 상승 비교로 사용하지 않는다. 이후 추가한 회차 생산·그림·Java 한글 출력의 효과도 이 점수에 포함되어 있지 않다.

HWP 진행 상태는 [양식 문서](LAYOUT.md)에 별도로 갱신한다. 현재 실제 한글에서 LEET·PSAT 샘플을 열고 PDF로 출력했으며, 위 초기 파일럿 시점의 ‘양식 출력 없음’ 기록과 구분한다.

## 텍스트 피드백 후보의 3쌍 비교 — 2026-10-07

LEET 합답형에서 핵심 판단을 건너뛰고 답을 고르는 문제를 줄이려는 프롬프트 후보를 시험했다. 고정된 `leet-norm` pilot 하나를 baseline·candidate 각각 3회 생성했다. 모델은 `gpt-6-astra`, 수정 최대 1회, humanizer 미적용이며 A/B 순서를 교대했다. 입력·DB·평가기를 동결하고 실제 생성에 사용된 brief/context/retrieval 18개 해시가 일치하는지 재검증했다. 실행 중 추가한 이미지 검토 기능은 이 동결 실험에 포함되지 않는다.

| 관찰 | Baseline | Candidate |
|---|---:|---:|
| 최종 모델 점수 / 4 (3회) | 2.750 / 2.875 / 3.000 | 2.750 / 2.875 / 2.875 |
| 최종 eligible | 3/3 | 3/3 |
| 초안 평가의 fatal 발생 | 0/3 | 1/3 |
| 수정이 필요했던 실행 | 0/3 | 1/3 |
| 모델 호출 수 | 15 | 18 |

**후보를 채택하지 않고 baseline을 유지했다.** 평균 차이 −0.0417은 작고 평가 변동도 관찰되어 실제 성능 저하의 통계적 증거로 해석하지 않는다. 개선 근거는 없으며, 후보 초안 1건에는 반례의 적용 범위가 빠져 추가 수정이 필요했다. 선택지 배열에서 핵심 보기의 판정이 필요해졌어도 실제 추론이 단순 대입이나 다른 반례로 우회되는 문제는 남았다.

33회 호출, 약 26.6분, 입력 997,310·출력 48,854토큰을 사용했다. 초안·최종본·수정·평가 원문과 비교·해시 감사는 로컬 `experiments/text-feedback-20261007/`에 보존했다. 추가 반복이나 자동 채택은 하지 않았다. 이는 한 공개 pilot의 모델 평가이며 전문가 승인, 다른 LEET 유형이나 PSAT의 성능을 입증하지 않는다.
