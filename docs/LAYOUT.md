# 한글 양식 연동 계약

승규님의 Java 도구가 시대인재 양식에 맞게 출력된다는 대화는 확인했지만, 현재 제공된 ZIP·로컬 작업 폴더·Downloads에서는 그 Java 소스/실행 JAR을 찾지 못했다. 기존 HWP 템플릿은 확보돼 있다. 도구가 없는 상태에서 동일 양식 출력이 된다고 주장하지 않는다.

현재 `candidate.json`은 문항 ID, 발문, 지문, 보기, 표, 선지, 정답, 해설을 분리한다. `layout-package`는 후보의 해시와 선택한 문제지·해설지 템플릿의 해시, 표·수식 확인 목록을 묶어 Java 도구에 전달할 manifest를 만든다. 템플릿을 수정하거나 폰트를 설치하지 않는다.

Java 어댑터가 받아야 하는 값: 문항 목록 JSON, 문제지 템플릿 경로, 해설지 템플릿 경로, 출력 디렉터리. 실제 메서드·CLI 옵션은 소스를 받은 뒤 맞춘다. 임의의 가상 옵션을 실행 가능한 명령처럼 제공하지 않는다.

연동 후 비교할 것은 문항 번호·선지 누락, 표 셀·단위, 수식 객체, 보기 박스, 다단·페이지 넘김, 글꼴 대체, 해설 번호·정답 일치다. 원본 양식과 렌더된 페이지를 나란히 보고 페이지별 결과를 저장한다. 픽셀 유사도만으로 내용 보존을 증명하지 않는다. 구조 검증과 시각 검증이 끝나기 전 `layout_verified=false`다.
