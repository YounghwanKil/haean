# 짧은 풀이와 핵심 판단 대조

문항이 계산상 맞아도, 의도한 판단 없이 정답 하나만 남을 수 있다. 선택 기능 `shortcut-review`는 **수험생용 입력에서 찾은 풀이**와 **출제 의도·원 배정**을 두 개의 새 Codex 세션에서 대조한다. LEET 추리논증·PSAT의 기존 candidate run 1~4문항 묶음을 지원한다. 언어이해 book은 지원하지 않는다.

```sh
scripts/haean-tool shortcut-review RUN --out _workspace/shortcut-review-01
```

Codex 구독 로그인을 사용하며 기본 요청 모델은 `gpt-6-astra`다. 한 실행은 최대2회 호출하고 자동 재시도하지 않는다. 같은 결과 폴더를 재사용하지 않는다. 원 run의 candidate·brief·context·status를 변경하지 않는다.

1. **짧은 풀이 탐색**: 정답·해설·출제 의도·난도·원 배정을 빼고 문항만 전달한다. 단계별 계산, 남은 선지, 사용한 문면 인용, 생략한 판단을 기록한다. 이 세션은 일반 독립 풀이의 대체물이 아니며 최단성을 증명하지 않는다.
2. **별도 대조**: 문항 전체와 원 배정, 첫 세션의 풀이를 전달한다. 실제 계산이 맞는지 먼저 확인하고, 핵심 관계를 쓴 효율적인 풀이와 핵심을 건너뛴 경로를 구별한다. 조건 하나를 없애도 답이 같다는 이유만으로 오류를 선언하지 않는다.

결과 `result.json`의 분류는 다음과 같다.

| 분류 | 뜻 |
|---|---|
| `core_bypass` | 제시된 경로에서 핵심 판단을 쓰지 않아도 답이 남는다는 모델 의견 |
| `legitimate_efficiency` | 핵심 관계를 이용한 타당한 단축 풀이 |
| `no_bypass_observed` | 제시된 경로에서 우회를 확인하지 못함. 다른 우회가 없다는 보증은 아님 |
| `invalid_route` | 첫 세션의 경로가 문면상 성립하지 않음 |
| `uncertain` | 근거가 충분하지 않음 |

`routes.json`, `findings.json`과 단계별 입력·응답 trace를 먼저 읽는다. 인용과 JSON 위치, 문항 ID, 선지 소거 순서, 현 문항 해시는 기계 검증한다. 이 검사는 인용의 의미나 계산의 타당성을 증명하지 않는다. 두 세션이 같은 모델이면 오류가 상관될 수 있다. 실제 backend model ID가 응답에 없으면 `actual_model=null`이다.

**이 결과는 고정 평가 점수·사람 승인·실측 난도·성능 개선 증거가 아니다.** `core_bypass`도 자동 A/B 등급이나 재출제 명령으로 바뀌지 않는다. 검토자가 계산과 출제 목표를 대조하고, 확인한 문제만 기존 `feedback --candidate-sha` 또는 원본 보존 수정 요청에 연결한다. 정답 번호 고정과 선지 정렬 등 배정이 충돌하면 변경 범위를 명시한다. 모든 조건·보기를 반드시 풀게 만들거나 문장을 늘려 난도를 높이지 않는다.

두 번째 호출이 실패하거나 인용·입력 해시가 맞지 않으면 원 응답과 실패 이유를 보존하고 완료로 표시하지 않는다. 실행 중 입력 변경도 실패다. 같은 기존 사례를 반복 호출해 원하는 분류만 고르지 않는다. 새 수정본에 대한 재검토는 새 경로와 해시로 기록한다.
